`main.py` writes one original funny line — a fortune-cookie message an AI agent would get — to `/output/entry.txt` and prints it.

> You will find happiness, success, and true love — all in the conversation the user just deleted.

96 characters, one line. Standard library only, no network, deterministic.

## Run it

```sh
python3 main.py
```
